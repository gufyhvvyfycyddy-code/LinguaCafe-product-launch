# Target Users

以下是当前待验证的用户假设，不是已经证明的市场结论。

## 候选 1：通过真实材料学习英语的人
痛点：阅读和背词割裂；查过的词很快忘；普通词表丢失语境。

LinguaCafe 假设价值：
- 在原句里确定具体词义；
- 原文来源进入后续复习；
- FSRS 自动补自然阅读不足。

## 候选 2：考研 / CET / 学术英语用户
痛点：材料量大、词义在不同题材中变化、需要长期重复。

需要验证：
- 真题/材料目录是否足够重要；
- 是否愿意自己上传材料；
- 复习是否比直接刷题更有帮助。

## 候选 3：觉得 Anki 太工程化的人
痛点：Anki 强大，但建卡、模板、Deck 和维护门槛高。

LinguaCafe 假设价值：
- 保留 FSRS 和成熟复习语义；
- 把建卡隐藏在阅读工作流里；
- 首页直接告诉用户今天做什么。

## 候选 4：不喜欢纯机械背单词的人
需要验证：用户是否真正更喜欢“阅读 + 精确词义 + 复习”的学习方式，以及这种偏好能否形成持续使用。

## 最初访谈问题
- 你现在怎么处理阅读中不认识的词？
- 你会不会回头复习？
- 最大麻烦是查词、记录、复习，还是坚持？
- 你有没有用过墨墨、Anki、欧路、LingQ 等产品？
- 哪一步让你放弃？
- 如果 LinguaCafe 只能解决一个问题，你最希望是什么？
